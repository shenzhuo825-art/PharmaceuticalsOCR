# 藥單辨識工作台

原生 HTML / CSS / JavaScript 介面，無前端套件或建置程序。目前僅顯示固定示範資料，沒有串接 OCR，也不會上傳或儲存圖片。重新整理會清除預覽與結果。

## 啟動

需要 Python 3。在專案根目錄開啟 PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File .\web\start.ps1
```

看到 `Serving` 訊息後，用電腦開啟 http://localhost:8080 。按 Ctrl+C 停止。腳本會固定使用自身所在的 web 資料夾，不受目前工作目錄影響。ExecutionPolicy Bypass 僅適用於這次啟動的 PowerShell 程序。

若 8080 已被使用，指定其他連接埠：

```powershell
powershell -ExecutionPolicy Bypass -File .\web\start.ps1 -Port 8081
```

亦可直接執行 `python .\web\serve.py --port 8080`。

## 手機開啟

1. 電腦和手機連接同一個區域網路，保持電腦及服務開啟。
2. 查看啟動腳本列出的 `LAN` 網址，選擇 Wi-Fi 或乙太網路的 IPv4。多張網卡可能列出多個網址，可執行 `ipconfig` 確認。
3. 手機瀏覽器開啟例如 `http://192.168.1.10:8080`。手機的 localhost 指的是手機自身，請使用電腦 IP。
4. 如無法連線，確認 Windows 網路設定為可信任的私人網路，並在 Windows 防火牆允許 Python 於私人網路通訊；若需新增輸入規則，限私人設定檔、TCP、指定連接埠及本機子網路。
5. 確認手機沒有連到訪客 Wi-Fi；路由器 AP／用戶端隔離會阻止裝置互通。VPN 也可能影響區域網路連線。

服務監聽 `0.0.0.0`，手機須使用實際 IP，不能使用 `0.0.0.0` 作為網址。此服務供本機與可信任的區域網路預覽，無需設定路由器對外轉發。

## 使用

- 選取或拖曳 JPG、PNG、WebP，或在手機點「拍攝藥單」。相機入口依手機及瀏覽器支援情況啟動系統相機或檔案選擇器，不使用需要 HTTPS 的即時鏡頭串流。
- 圖片預覽後點「顯示示範辨識結果」。姓名、藥盤、日期、天數及藥品內容均為示範，與圖片無關。
- 展開「檢視示範 JSON」可檢視或複製現有 OCR 欄位格式。
- 區域網路 HTTP 瀏覽器可能禁止剪貼簿 API，複製失敗時會選取 JSON 並提示手動複製。
- 重設或換圖會清除先前結果。損壞圖片及不支援的檔案會顯示錯誤。

## 人工驗收

以桌面及手機寬度開啟，確認沒有水平溢出；檢查選圖、拖曳、損壞圖片、非圖片、未選圖直接操作、換圖、重設、示範標示及 JSON 複製。手機實機須另外驗證區域網路連線與相機入口。
